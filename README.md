# HueForge Tools
Static site (no build step): open `index.html`, or serve the folder (`python3 -m http.server`). Hosted on GitHub Pages.
Each tool is a folder with `index.html`. Shared code in `assets/`: `common.css`, `library.js` (filament library, localStorage), `projects.js` (saved work, IndexedDB), `ui.js` (header, drop zone, download).
